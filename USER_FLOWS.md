# Användarflöden (User Flows)

## 1. Uppstart & Autentisering
1.  Användaren navigerar till URL.
2.  PIN-kodsskärm visas.
3.  Användaren anger `1234`.
4.  Appen laddar sessioner och historik.

## 2. Förberedelse för träning
1.  Användaren skapar en ny session (t.ex. "Morgonpass").
2.  Användaren väljer klubba (t.ex. "7-Iron").
3.  Användaren placerar mobilen så att simulatorns skärm syns i ramen.
4.  Användaren klickar på "START MONITORING".

## 3. Under träningen
1.  Användaren slår ett slag.
2.  Simulatorn visar data.
3.  Appen detekterar förändring -> Skickar till AI.
4.  AI analyserar -> UI visar betyg och tips.
5.  Röstfeedback läser upp: "Snyggt slag! Bärvidd 145 meter. Tänk på att..."
6.  Användaren slår nästa slag.

## 4. Analys & Frågor
1.  Användaren klickar på "Fråga Coachen".
2.  Användaren skriver: "Varför har jag så hög spin på mina slag?".
3.  AI-coachen svarar baserat på de senaste 5 slagen i databasen.
4.  Användaren kollar "Trends" för att se om bollhastigheten ökat under passet.
